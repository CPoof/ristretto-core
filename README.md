# Ristretto Core

Forked from [schnorrkel](https://github.com/paritytech/schnorrkel) to update dependencies and keep core features. 

We keep Schnorr signatures on [Ristretto](https://ristretto.group) compressed Ed25519 points, as well as [related](https://github.com/sipa/bips/blob/bip-taproot/bip-0340.mediawiki) protocols like HDKD.
